# Sources

Checked on **24 September 2026**.

1. [UN Geneva web style guide](https://www.ungeneva.org/en/styleguide): “In line with the United Nations Editorial Manual, the website uses British English unless otherwise declared.”
2. [United Nations Editorial Manual Online](https://editorial.un.org/): guidance on “per cent” states that the words should normally be written out, while `%` may be used in tables where space is limited.
3. *Concise Oxford English Dictionary*, 12th edition: spelling authority; use the first-listed form under the UN framework.

These sources establish the editorial baseline. They do not establish that a factual claim is true, current or proportionate. Source factual prose to the original dataset or report and include its date. If a report is quoted in a standfirst or post, cite it in the page footer with a link.

Some web style guidance can change. Re-check the manual before treating this v0.1 package as a substitute for current institutional guidance.
